# KXStitch thread schemes

`dmc.xml` and `anchor.xml` come unmodified from the `schemes/` folder of
[KXStitch](https://invent.kde.org/graphics/kxstitch), the KDE cross-stitch editor.

The RGB values are approximations: thread manufacturers do not publish official RGB values.
`npm run build:threads` turns these files into `src/core/threads/data/*.json`.
